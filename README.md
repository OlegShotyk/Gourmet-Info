# Гурман-Інфо — сайт підбору сиру та вина

Багатосторінковий адаптивний сайт каталогу крафтових сирів та вин «Гурман-Інфо» (Gourmet-Info) — випускний проєкт (MVP) самостійної роботи.
Допомагає підібрати гастрономічну пару «сир + вино», розрахувати сирну тарілку для компанії й залишити запит сомельє.

**Сайт (Vercel):** https://gourmet-info.vercel.app  
**Репозиторій:** https://github.com/OlegShotyk/Gourmet-Info

## Самостійна робота: що нового

- **5 сторінок** зі спільною шапкою, підвалом і активним пунктом меню (`aria-current="page"`):
  `index.html` (головна), `collection.html` (каталог і галерея), `planner.html` (калькулятор), `about.html` (про нас, відео), `contact.html` (форма, карта, погода).
- **Світла / темна тема** (Tailwind `darkMode: 'class'`): перемикач у шапці, вибір зберігається в `localStorage`,
  без вибору — тема системи (`prefers-color-scheme`). Кольори — CSS-змінні (`src/input.css`), утиліти `dark:` — фонові фото, логотип, карта, іконки.
  Тема ставиться ще до відмальовування (вбудований скрипт у `<head>`) — без «блимання».
- **Фонові фото на кожній сторінці** — світлі для світлої теми, темно-бордові для темної (Unsplash, оброблені: кадрування, тонування, AVIF + WebP, 960 / 1920 px).
- **Mock-дані `data.json`**: 9 сирів, 8 вин, 6 перевірених пар. Завантаження `fetch` + `async/await` (`js/data.js`), перевірка структури,
  тайм-аут, повідомлення про помилку з кнопкою «Спробувати ще раз». Дані використовують слайдер на головній, каталог і калькулятор.
- **Каталог з фільтрами** (`js/catalog.js`): категорія, рівень, пошук, сортування; стан — в адресі (`?kind=wines&level=premium`), картка веде в калькулятор.
- **Переходи між сторінками з параметрами**: `planner.html?pair=…|cheese=…|wine=…|preset=…|open=…`, `contact.html?topic=…`;
  склад тарілки з калькулятора потрапляє у форму через `sessionStorage`.
- **Vercel Web Analytics** (`js/analytics.js`, лише на продакшн-домені) і Open Graph для кожної сторінки (`assets/images/og-image.jpg`, 1200×630).

## Можливості

- Секції: головний екран, переваги, послуги, «Як це працює», відео, «Про нас», форма зворотного зв’язку, контакти.
- Форма зворотного зв’язку (ЛР №9): ім’я, email, телефон `+380XXXXXXXXX`, тема, згода; повідомлення — необов’язкове (якщо заповнене — від 10 символів).
  Клієнтська валідація на RegEx + JavaScript при натисканні «Надіслати», стани normal / focus / error / success,
  `aria-invalid` / `aria-describedby`, модальне вікно успіху (Escape, клік по фону, focus trap).
  Реального надсилання на сервер немає — це демонстрація успішного надсилання.
- «Колекція пар» (ЛР №10): слайдер Swiper.js 11 (6 пар, автопрогортання з паузою, стрілки, пагінація, свайпи;
  1 / 2 / 3 слайди на телефоні / планшеті / десктопі) і галерея Fancybox v5 (альбом, зум, мініатюри);
  ефект друку Typed.js у першому екрані. Бібліотеки підключено через CDN jsDelivr, ініціалізація — js/plugins.js.
- «Конструктор сирної тарілки» (ЛР №11): гості (лише ціле число 1–50), формат вечора, конкретні сири й вина
  з меню з фото (рівні Класика / Крафт / Преміум), «Перевірені пари» з секції «Колекція», супровід і сомельє —
  вага кожного сорту, пляшки й вартість. Кнопки «Підібрати пару» й «Обрати формат» ведуть до калькулятора.
  Захищений від Edge Cases (дробові й нецифрові символи не вводяться, порожнє поле, 0, > 50, жодного сиру,
  підмінені в DevTools значення, відсутні елементи); вивід лише через textContent. Код — js/widget.js (Vanilla JS, IIFE).
- Адаптивна верстка mobile-first (320–1440 px), мобільне меню.
- Вбудоване відео YouTube (фасад: плеєр вантажиться після натискання), карта Google Maps та інформер погоди — з ледачим завантаженням.
- Фонове відео в секції послуг з кнопкою паузи та підтримкою `prefers-reduced-motion`.
- Доступність: семантичні теги, один `h1`, видимий фокус, `alt` та `title` для медіа.

## Технології

## Структура

```
index.html            — головна сторінка
collection.html       — колекція: каталог з фільтрами та галерея
planner.html          — калькулятор сирної тарілки
about.html            — про нас, «Як це працює», відео
contact.html          — форма зворотного зв’язку, карта, погода
data.json             — Mock-дані: сири, вина, перевірені пари
js/data.js            — завантаження data.json (fetch, async/await, обробка помилок)
js/catalog.js         — каталог колекції з фільтрами
js/theme.js           — перемикач теми, localStorage
js/analytics.js       — Vercel Web Analytics
css/tailwind.css      — скомпільовані стилі (Tailwind + css/style.css)
css/style.css         — власні стилі: фокус, фон Hero, медіафрейми, анімація меню
src/input.css         — вхідний файл збірки Tailwind
tailwind.config.js    — тема з дизайн-системи (кольори, шрифти, шкала)
js/menu.js            — мобільне меню
js/bg-video.js        — пауза фонового відео
js/lazy-embeds.js     — фасад відео, ледаче підключення карти й інформера
js/validation.js      — валідація форми, підказка формату телефону, модальне вікно
js/plugins.js         — ініціалізація Swiper.js, Fancybox v5 і Typed.js (CDN)
js/widget.js          — калькулятор сирної тарілки (ЛР №11)
assets/               — зображення, іконки, відео
_headers              — заголовки кешування для Netlify
```

## Запуск локально

```bash
npm install          # Tailwind CLI та Prettier
npm run build:css    # зібрати css/tailwind.css після зміни класів
```

Сайт завантажує `data.json` через `fetch`, тому відкривати його треба через локальний сервер, а не подвійним клацанням (`file://`):

```bash
py -m http.server 8080    # або: npx serve .
```

Потім відкрийте `index.html` через локальний сервер (наприклад, розширення Live Server у VS Code) —
відео YouTube і віджет погоди не працюють при відкритті файлу напряму (`file://`).

## Реліз і CI/CD (ЛР №12)

- **Lighthouse-оптимізація:** шрифти на власному хостингу (`assets/fonts`), бібліотеки Swiper / Fancybox / Typed
  підвантажуються на вимогу (`js/plugins.js`), фонове відео — коли секція наближається до екрана,
  зображення першого екрана — AVIF/WebP у двох розмірах, SVG стиснуто SVGO; `robots.txt`, `sitemap.xml`, canonical на Vercel.
- **Конвеєр** `.github/workflows/deploy.yml`: push у `main` → перевірка (збірка Tailwind, синтаксис JS, html-validate)
  → `vercel deploy --prod` → Lighthouse CI продакшну (`lighthouserc.json`). Pull request — лише перевірка.
- Автодеплой Vercel з Git вимкнено (`vercel.json`), тож на сайт потрапляє лише код, що пройшов перевірку.
  Секрети репозиторію: `VERCEL_TOKEN`, `VERCEL_ORG_ID`, `VERCEL_PROJECT_ID`.
