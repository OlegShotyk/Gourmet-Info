# Гурман-Інфо — лендинг підбору сиру та вина

Односторінковий адаптивний лендинг каталогу крафтових сирів та вина «Гурман-Інфо» (Gourmet-Info).
Допомагає підібрати гастрономічну пару «сир + вино» під страву, бюджет чи настрій і залишити запит на консультацію.

**Live demo (Netlify):** https://gourmet-info.netlify.app

## Можливості

- Секції: головний екран, переваги, послуги, «Як це працює», відео, «Про нас», форма запиту, контакти.
- Адаптивна верстка mobile-first (320–1440 px), мобільне меню.
- Вбудоване відео YouTube (фасад: плеєр вантажиться після натискання), карта Google Maps та інформер погоди — з ледачим завантаженням.
- Фонове відео в секції послуг з кнопкою паузи та підтримкою `prefers-reduced-motion`.
- Доступність: семантичні теги, один `h1`, видимий фокус, `alt` та `title` для медіа.

## Технології

- HTML5, CSS3, JavaScript (без фреймворків)
- [Tailwind CSS 3](https://tailwindcss.com) — збірка через Tailwind CLI
- Netlify (хостинг, форми, заголовки кешування)

## Структура

```
index.html            — сторінка лендингу
css/tailwind.css      — скомпільовані стилі (Tailwind + css/style.css)
css/style.css         — власні стилі: фокус, фон Hero, медіафрейми, анімація меню
src/input.css         — вхідний файл збірки Tailwind
tailwind.config.js    — тема з дизайн-системи (кольори, шрифти, шкала)
js/menu.js            — мобільне меню
js/bg-video.js        — пауза фонового відео
js/lazy-embeds.js     — фасад відео, ледаче підключення карти й інформера
assets/               — зображення, іконки, відео
_headers              — заголовки кешування для Netlify
```

## Запуск локально

```bash
npm install          # Tailwind CLI та Prettier
npm run build:css    # зібрати css/tailwind.css після зміни класів
```

Потім відкрийте `index.html` через локальний сервер (наприклад, розширення Live Server у VS Code) —
відео YouTube і віджет погоди не працюють при відкритті файлу напряму (`file://`).
