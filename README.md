# Гурман-Інфо — лендинг підбору сиру та вина

Односторінковий адаптивний лендинг каталогу крафтових сирів та вина «Гурман-Інфо» (Gourmet-Info).
Допомагає підібрати гастрономічну пару «сир + вино» під страву, бюджет чи настрій і залишити запит на консультацію.

**Live demo (Netlify):** https://gourmet-info.netlify.app  
**Vercel:** https://gourmet-info.vercel.app  
**GitHub Pages:** https://olegshotyk.github.io/Gourmet-Info/  
**Репозиторій:** https://github.com/OlegShotyk/Gourmet-Info

## Можливості

- Секції: головний екран, переваги, послуги, «Як це працює», відео, «Про нас», форма зворотного зв’язку, контакти.
- Форма зворотного зв’язку (ЛР №9): ім’я, email, телефон `+380XXXXXXXXX`, тема, згода; повідомлення — необов’язкове (якщо заповнене — від 10 символів).
  Клієнтська валідація на RegEx + JavaScript при натисканні «Надіслати», стани normal / focus / error / success,
  `aria-invalid` / `aria-describedby`, модальне вікно успіху (Escape, клік по фону, focus trap).
  Реального надсилання на сервер немає — це демонстрація успішного надсилання.
- «Колекція пар» (ЛР №10): слайдер Swiper.js 11 (6 пар, автопрогортання з паузою, стрілки, пагінація, свайпи;
  1 / 2 / 3 слайди на телефоні / планшеті / десктопі) і галерея Fancybox v5 (альбом, зум, мініатюри);
  ефект друку Typed.js у першому екрані. Бібліотеки підключено через CDN jsDelivr, ініціалізація — js/plugins.js.
- «Конструктор сирної тарілки» (ЛР №11): гості (лише ціле число 1–50), формат вечора, конкретні сири й вина
  з меню з фото (рівні Класика / Крафт / Преміум), «Перевірені пари» з секції «Колекція», супровід і сомельє —
  вага кожного сорту, пляшки й вартість. Кнопки «Підібрати пару» й «Обрати формат» ведуть до калькулятора.
  Захищений від Edge Cases (дробові й нецифрові символи не вводяться, порожнє поле, 0, > 50, жодного сиру,
  підмінені в DevTools значення, відсутні елементи); вивід лише через textContent. Код — js/widget.js (Vanilla JS, IIFE).
- Адаптивна верстка mobile-first (320–1440 px), мобільне меню.
- Вбудоване відео YouTube (фасад: плеєр вантажиться після натискання), карта Google Maps та інформер погоди — з ледачим завантаженням.
- Фонове відео в секції послуг з кнопкою паузи та підтримкою `prefers-reduced-motion`.
- Доступність: семантичні теги, один `h1`, видимий фокус, `alt` та `title` для медіа.

## Технології

- HTML5, CSS3, JavaScript (без фреймворків)
- [Tailwind CSS 3](https://tailwindcss.com) — збірка через Tailwind CLI
- Netlify, GitHub Pages, Vercel (хостинг з автоматичним деплоєм з GitHub)

## Структура

```
index.html            — сторінка лендингу
css/tailwind.css      — скомпільовані стилі (Tailwind + css/style.css)
css/style.css         — власні стилі: фокус, фон Hero, медіафрейми, анімація меню
src/input.css         — вхідний файл збірки Tailwind
tailwind.config.js    — тема з дизайн-системи (кольори, шрифти, шкала)
js/menu.js            — мобільне меню
js/bg-video.js        — пауза фонового відео
js/lazy-embeds.js     — фасад відео, ледаче підключення карти й інформера
js/validation.js      — валідація форми, підказка формату телефону, модальне вікно
js/plugins.js         — ініціалізація Swiper.js, Fancybox v5 і Typed.js (CDN)
js/widget.js          — калькулятор сирної тарілки (ЛР №11)
assets/               — зображення, іконки, відео
_headers              — заголовки кешування для Netlify
```

## Запуск локально

```bash
npm install          # Tailwind CLI та Prettier
npm run build:css    # зібрати css/tailwind.css після зміни класів
```

Потім відкрийте `index.html` через локальний сервер (наприклад, розширення Live Server у VS Code) —
відео YouTube і віджет погоди не працюють при відкритті файлу напряму (`file://`).
